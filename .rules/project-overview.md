# 프로젝트 개요

## WWUA Mod Manager

명조(Wuthering Waves) 모드를 관리하기 위한 데스크톱 애플리케이션입니다.

## 핵심 UX 흐름

1. 사용자가 캐릭터를 선택한다
2. 해당 캐릭터에 적용 가능한 모드 목록(썸네일 + 토글)을 확인한다
3. 모드를 클릭하면 오른쪽 패널에서 상세 정보를 본다
4. 모드는 안전하게 Enable/Disable 할 수 있어야 한다

## MVP 범위 (우선 구현)

에이전트는 아래 기능을 최우선으로 구현해야 합니다.

- 캐릭터 선택 그리드 UI
- 캐릭터별 모드 리스트 (이미지 중심 + 토글)
- 모드 상세 정보 패널 (프리뷰 + 메타데이터)
- 로컬 모드 Import (ZIP 또는 폴더)
- 모드 Enable/Disable (폴더 이동 기반)
- Preset 저장 및 적용
- Backup / Restore 도구

## MVP에서 제외되는 기능

- 온라인 마켓/브라우저 통합
- 안티치트 우회, DLL 인젝션 등 위험 기능
- 게임 바이너리 직접 수정
- 자동 업데이트 서버 연동
- 멀티 게임 지원

## 개발 우선순위

1. UX 명확성
2. 안전한 모드 토글
3. 컴포넌트 재사용성
4. 런처 스타일 UI 완성도
5. 빠른 MVP 반복 개발
